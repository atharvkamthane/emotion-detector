# Emotion Detector

## Project Description

This project is an AI-based Emotion Detector application developed using the Watson NLP library.

The application analyzes a given text and detects five emotions:

- Anger
- Disgust
- Fear
- Joy
- Sadness

It also identifies the dominant emotion expressed in the text.

## Technologies Used

- Python
- Watson NLP
- Flask
- Requests
- Pylint
- Unit Testing
